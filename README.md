# Cybersecurity Quiz App

A front-end cybersecurity quiz app where users answer security questions, track score, review results, and save their best score locally.

## Live Demo

https://jfoster294.github.io/cybersecurity-quiz-app/

## Features

- Multiple-choice cybersecurity questions
- Category filter
- Progress tracker
- Score calculation
- Answer feedback
- Final results screen
- Review correct and incorrect answers
- Save best score with local storage
- Restart quiz
- Responsive design for mobile and desktop

## Categories

- Phishing
- Passwords
- Malware
- Networking

## Built With

- HTML
- CSS
- JavaScript
- Local Storage

## Project Goal

This project was built as part of my front-end developer portfolio to practice quiz logic, conditional rendering, scoring, category filtering, local storage, and responsive design while connecting front-end development with cybersecurity.
